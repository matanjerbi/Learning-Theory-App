# תאוריה בקטנה

אפליקציית Android ללימוד תאוריה לרישיון B, שנבנתה במיוחד לבעלי הפרעות קשב ולקויות למידה.

## מה יש בפנים
- **סבבים קצרים** (3–10 שאלות). שאלה אחת על המסך, כפתורים גדולים.
- **חזרה מרווחת (Leitner):** שאלה שטעית בה חוזרת עוד באותו סבב ומחר. שאלה שאתה יודע חוזרת אחרי 3, 7, 16 ו-35 יום.
- **משוב מיידי:** צבע, רטט והסבר קצר (כשיש).
- **גיוון:** שאלה אמריקאית, "נכון / לא נכון", וזיהוי תמרור מהיר עם טיימר.
- **"תן לי משהו":** לחיצה אחת, והאפליקציה בוחרת מה ללמוד.
- **מוכנות למבחן:** אחוז כללי ואחוז לכל נושא, וגם רצף ימים.
- **תרגול ומבחן בשמע:** מדמה את מבחן התאוריה בשמע של משרד הרישוי.
- **מבחן דמה:** 30 שאלות, 40 דקות, צריך 26 כדי לעבור.
- **נגישות:** גודל טקסט, ריווח אותיות, הקראה (TTS בעברית) וקצב הקראה.
- **תזכורת יומית** בשעה שבוחרים.

## מקור השאלות
1,276 שאלות לרישיון B, מהמאגר הרשמי של משרד התחבורה והבטיחות בדרכים ב-data.gov.il (CC-BY).
העיבוד, התמונות ו-49 ההסברים הראשונים לקוחים מ-[LAMED+](https://github.com/Sergey-Bar/lamed-plus) (MIT).
השאלות והתמונות לא שמורות בריפו: ה-workflow מוריד אותן בכל בנייה (גרסה נעולה) ומריץ `scripts/build-data.py`.

## בנייה
כל push ל-`main` מריץ GitHub Actions: הורדת המאגר, בדיקות, יצירת פרויקט ה-Android (`npx cap add android` ואחריו `scripts/patch-android.py`), אייקונים, בניית APK ופרסום Release.
בדיקות מקומיות: `npm test` (דורש קודם את `www/questions.js`).
